# วิสัยทัศน์ Jimmy AI Telegram — "AI Control Center"

> บันทึกจากชุดสนทนาต้นฉบับ (ย้ายจากไฟล์ Untitled-8, 2026-08-22)
> ใช้เป็น requirement หลักสำหรับการพัฒนา Phase ถัดไป

## 🎯 เป้าหมาย

Jimmy_bot ไม่ใช่แค่ "บอทรับคำสั่ง" แต่ต้องเป็น **ผู้ช่วยที่คิดร่วมกับเรา** และ Telegram ตัวเดียวกลายเป็น AI Control Center ของงานทั้งหมด

| เมนู | คำอธิบาย |
|---|---|
| 💬 คุยกับ AI | สนทนาธรรมดา |
| 🎨 สร้างภาพ | image generation |

- "สร้างภาพโปรโมตให้หน่อย"
- "เขียนโพสต์จากภาพนี้"
- "โค้ดชุดนี้ error ตรงไหน"
- "ช่วยสร้างปุ่ม LINE ให้ที"
- "สรุปสมาชิกกิจกรรมวันนี้"

## 🔐 ระบบสิทธิ์ 2 ระดับ (สำหรับงานโค้ด/ระบบ)

### ระดับ 1 — ปลอดภัย → ทำได้ทันที
- อ่านโค้ด
- เขียนโค้ด
- สร้างไฟล์
- แก้ไฟล์

### ระดับ 2 — ต้องกดยืนยัน → Bot ต้องถามก่อน
- แก้ Database
- Deploy
- Restart Server
- ลบไฟล์
- แก้ ENV
- ส่ง Broadcast

ตัวอย่าง flow:

```
Bot: กำลังจะ Restart pg77-api
[✅ ยืนยัน]
[❌ ยกเลิก]
```

เป้าหมาย: ป้องกันเหตุ "AI เข้าใจผิดแล้วไปแก้ Production เอง"

## 🧠 สมอง 4 ชั้น (Understand → Analyze → Suggest → Confirm)

```
เรา: "โพสต์อันนี้ลง Telegram"
        ↓
1. เข้าใจคำสั่ง
        ↓
2. วิเคราะห์ก่อนทำ
        ↓
3. แนะนำกลับ ถ้ามีทางที่ดีกว่า
        ↓
4. ให้เรายืนยัน / แล้วค่อยทำ
```

ตัวอย่าง:
- สั่ง: "โพสต์ภาพนี้ลง Telegram ให้ที"
- บอทไม่ควรตอบแค่ "โพสต์แล้ว" แต่ควรย้อนว่า:
  > ภาพนี้ใช้ได้ครับ
  > แต่ข้อความยาวเกินสำหรับโพสต์เร็ว
  > ผมแนะนำตัดเหลือ 3 บรรทัด และเพิ่ม CTA ท้ายโพสต์
  >
  > [ใช้แบบเดิม] [ใช้แบบแนะนำ] [แก้เพิ่ม]
